# Tabletop Design Studio: description

A single Claude skill for designing tabletop games: war games, miniatures games, board games and card games.

It routes each request to one of nine modes (concept, mechanics, balance and odds, cards, rules writing, scenarios and maps, components and production, playtesting, and gates and status), then reads only the reference material that mode needs.

It is built from the author's own separate tabletop skills, merged into one package. Video game and engine material has been removed.
