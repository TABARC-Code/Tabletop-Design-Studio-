# Audit Rubric

Score from 0 to 100. Use Red, Orange, Yellow, Green, Blue bands.

## Bands

| Score | Colour | Meaning |
|---:|---|---|
| 0–39 | Red | Broken, excluding, highly confusing, or actively damaging |
| 40–54 | Orange | Serious friction, repeated failures, likely design risk |
| 55–69 | Yellow | Functional but inconsistent, audience-dependent, needs refinement |
| 70–84 | Green | Strong, reliable, publishable with normal polish |
| 85–100 | Blue | Distinctive strength, memorable advantage, unusually successful |

## Evidence rules

Each score should include:

```yaml
score:
colour:
evidence:
affected_testers:
confidence:
recommendation:
```

## Default categories

- Rule clarity
- Onboarding
- Turn flow
- Pacing

- Balance
- Player agency

- Replayability
- Theme integration
- Component usability
- Accessibility
- Emotional arc
