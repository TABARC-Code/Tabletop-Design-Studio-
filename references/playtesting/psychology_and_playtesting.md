# Psychology and Playtesting Reference

Playtesting studies how people perceive, misread, optimise, resist, enjoy, and emotionally react to a game system.

## Core principle

Players do not test mechanics in isolation. They test experience.

A rule may be mathematically sound and still feel unfair. A mechanic may be simple and still be misunderstood. A theme may be rich and still be ignored if the incentives point elsewhere.

## Psychological layers

### Cognitive layer

Watch for misread rules, long pauses, repeated lookup, memory overload, analysis paralysis, and confusion between similar icons or terms.

### Emotional layer

Watch for excitement, frustration, boredom, relief, resentment, satisfaction, and perceived unfairness.

### Social layer

Watch for alpha-player behaviour, quiet-player withdrawal, social pressure, betrayal discomfort, argument escalation, and teaching imbalance.

### Motivational layer

| Motivation | Wants |
|---|---|
| Mastery | Skill expression, improvement, efficiency |
| Discovery | New systems, surprises, hidden depth |
| Story | Character, arc, emotional consequence |
| Social | Shared laughter, table energy, belonging |
| Competition | Fair contest, rankings, optimisation |
| Creation | Painting, building, customising, world-making |
| Simulation | Plausibility, fidelity, systemic logic |

### Behavioural layer

This is the strongest evidence.

Examples:

- A player says rules are clear but checks the rulebook every turn.
- A player says combat is fun but avoids combat.
- A player says trading is powerful but nobody trades.
- A player says the game is balanced but every winner uses the same route.

## Common playtesting distortions

- First-play bias
- Loss aversion
- Illusion of control
- Sunk cost commitment
- Optimisation drift
- Observer effect
- Social masking

## Interpretation rule

Do not ask only, “Did they like it?”

Ask:

- What did they misunderstand?
- What did they ignore?
- What did they repeat?
- What did they exploit?
- Where did energy rise or drop?
- Which complaints match the target audience?
- Which complaints come from persona mismatch?
